# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub Security Advisories:

**https://github.com/Mendl-Labs/BacktestingCore/security/advisories/new**

Do not open a public GitHub issue for security vulnerabilities, and do not report them to a personal email address. Reporting through GitHub Security Advisories ensures the report stays private between you and the maintainers until a fix is available.

We will acknowledge new reports and work with you to understand and address the issue as quickly as possible.
